기성집행서 사용 설명서

기성집행서는 아마란스10의 프로젝트와 입고금액을 가져와, 프로젝트마다 얼마를 쓰기로 했고(실행예산) 얼마를 썼는지(매입금액), 그래서 얼마가 남는지(예상 이익)를 한눈에 보여 주는 프로그램입니다.

그림 위의 1 같은 번호는 아래 설명의 번호와 같습니다. 그림을 누르면 새 탭에서 크게 볼 수 있습니다. 그림에 나온 프로젝트와 금액은 설명을 위한 예시입니다.

처음이라면 이 순서대로

집행서 한 건을 만드는 전체 흐름입니다. 각 단계를 누르면 자세한 설명으로 이동합니다.

  1. 로그인아이디·비밀번호 입력
  2. 프로젝트 고르기새 버전 만들기
  3. 매입금액 불러오기아마란스10 입고금액
  4. 실행예산 입력 · 저장잔액·집행률 자동 계산
  5. 확정 · 인쇄결재용 문서 출력

권한에 따라 보이는 메뉴가 다릅니다. 조회자는 보기·인쇄만, 작성자는 집행서 작성까지, 관리자는 설정과 사용자 관리까지 할 수 있습니다. 버튼이 안 보이면 관리자에게 권한을 확인하세요.

1. 로그인 1단계

아마란스10 메뉴에서 들어오면 자동으로 로그인됩니다. 인터넷 주소로 직접 들어왔다면 아래처럼 로그인합니다.

  1. 로그인 ID — 관리자에게 받은 아이디(보통 사번)를 넣습니다.
  2. 비밀번호 — 처음에는 관리자에게 받은 임시 비밀번호를 넣습니다.
  3. 로그인을 누릅니다.
  4. 사용 설명서 보기 — 로그인 전에도 이 설명서를 열 수 있습니다.

처음 로그인하면 비밀번호부터 바꿉니다

임시 비밀번호로 들어오면 비밀번호 변경 화면이 나옵니다. 현재 비밀번호(임시 비밀번호)와 새 비밀번호를 두 번 넣고 변경하고 시작하기를 누르세요.

  • 새 비밀번호는 10자 이상, 영문·숫자·기호 중 두 종류 이상을 섞어야 합니다.
  • 로그인을 여러 번 틀리면 잠시 막힙니다. 화면에 나온 시간이 지난 뒤 다시 해 보세요.
  • 비밀번호를 잊었다면 관리자에게 비밀번호 초기화를 요청하세요.
설치 직후 맨 처음 관리자 로그인 (관리자만)

프로그램을 처음 실행하면 관리자 계정 admin 이 자동으로 만들어집니다. 임시 비밀번호는 서버의 data\logs\app-(날짜).log 파일에 최초 관리자 계정을 만들었습니다 라는 줄로 한 번만 기록됩니다. 로그인해서 비밀번호를 바꾼 뒤, 사용자 화면에서 실제 사용자를 등록하세요.

2. 화면 둘러보기

로그인하면 기성집행서 화면이 열립니다. 대부분의 일은 이 화면 하나에서 끝납니다.

  1. 왼쪽 메뉴 — 화면을 바꿉니다. 관리자에게는 설정 메뉴가 더 보입니다.
  2. 프로젝트 줄 — 어떤 프로젝트의 집행서를 볼지 고르고, 새 버전을 만듭니다.
  3. 버전 줄 — 이 프로젝트의 집행서 버전(v1, v2 …)과 상태(작성중/확정)를 봅니다.
  4. 요약 카드 — 계약금액·실행예산·매입금액·예상 이익이 자동으로 계산됩니다.
  5. 입고금액 불러오기 — 아마란스10에서 매입금액을 가져옵니다. 그 아래에 분류별 표가 있습니다.
  6. 사용 설명서 — 언제든 오른쪽 위에서 이 설명서를 새 탭으로 엽니다.
  1. 사용 설명서 — 지금 보고 있는 이 설명서입니다.
  2. 내 이름 — 누르면 비밀번호 변경과 로그아웃이 나옵니다.

아무 작업 없이 8시간이 지나면 자동으로 로그아웃됩니다(관리자가 바꿀 수 있음).

3. 집행서 만들기

집행서는 프로젝트마다 버전으로 만듭니다. 작성중인 버전에 매입금액을 불러오고 실행예산을 넣은 뒤, 다 되면 확정합니다. 이 장은 작성자 이상 권한이 필요합니다.

2단계 프로젝트를 고르고 새 버전 만들기

  1. 프로젝트 검색 — 코드나 이름 일부를 넣으면 목록이 좁혀집니다.
  2. 프로젝트 — 집행서를 만들 프로젝트를 고릅니다.
  3. 이전 버전 복제 — 지금 버전의 실행예산·비고를 그대로 가져와 새 버전을 만듭니다.
  4. 설정으로 새 버전 — 빈 집행서를 새로 만듭니다. 처음이면 이 버튼을 누르세요.
  5. 집행서 버전 — 만든 버전을 골라 봅니다. 옆에 작성중/확정 상태가 보입니다.
  6. 버전 확정 — 작성이 끝나면 누릅니다(5단계).
  • 목록에 새 프로젝트가 없으면 오른쪽 위 프로젝트 동기화를 누르세요. 아마란스10에서 프로젝트와 계약금액을 다시 가져옵니다.
  • 버전은 만든 순간의 분류와 계약금액을 그대로 간직합니다. 나중에 설정이 바뀌어도 이미 만든 버전은 바뀌지 않습니다.

3단계 매입금액 불러오기

  1. 입고 시작일 — 처음에는 최근 3개월이 들어 있습니다. 프로젝트 시작일로 바꾸세요.
  2. 입고 종료일 — 보통 오늘 날짜 그대로 둡니다.
  3. 기존 내역 지우고 다시 조회 — 체크하면 이미 불러온 입고를 모두 지우고 새로 채웁니다. 평소에는 비워 두세요.
  4. 매입금액 불러오기를 누르면 표의 매입금액이 채워집니다.
  • 여러 번 불러와도 같은 입고는 한 번만 들어갑니다. 기간을 나눠서 차례로 불러와도 됩니다.
  • 한 번에 고를 수 있는 기간은 기본 최대 366일입니다. 더 길게 필요하면 관리자가 접속 · 보안에서 늘릴 수 있습니다.
  • 분류에 연결되지 않은 품번은 빠집니다. 빠진 품번은 표 아래 입고 상세 내역에 안내됩니다.

4단계 실행예산 입력하고 저장하기

  1. 중분류 — 소분류가 있는 중분류는 오른쪽에 소분류가 줄줄이 나옵니다.
  2. 소분류 — 소분류가 없는 중분류(배관자재 등)는 한 줄로 보입니다.
  3. 실행예산 — 숫자만 입력합니다. 칸을 벗어나면 쉼표가 붙습니다.
  4. 소 계 — 소분류가 2개 이상인 중분류의 합계입니다. 자동 계산됩니다.
  5. ○○ 합계 — 대분류(자재비 등)의 합계입니다.
  6. 저장 — 반드시 눌러야 기록됩니다.
  7. 인쇄 — 결재용 A4 문서를 인쇄합니다(4장).
  8. Excel 내보내기 — 같은 내용을 Excel 파일로 받습니다(4장).

Enter 다음 칸으로   Shift + Enter 이전 칸으로

  • 입력하는 즉시 예산잔액·집행률·소계·합계와 위쪽 요약 카드가 바뀝니다.
  • 예산보다 더 쓰면 잔액이 △ 빨간 글씨로, 집행률 막대가 빨간색으로 보입니다.
  • 저장 전에는 버전 줄에 저장하지 않은 변경이 보이고, 다른 화면으로 가려 하면 확인 창이 뜹니다.
  • 다른 사람이 같은 버전을 먼저 저장했다면 덮어쓰지 않고 알려 줍니다. 화면을 새로 고친 뒤 다시 입력하세요.

합계는 어떻게 보나요?

  1. 대분류 합계 — 그 대분류에 속한 줄의 합입니다. 소계를 한 번 더 더하지 않습니다.
  2. 전체 합계 — 모든 대분류 합계를 더한 값으로, 요약 카드의 실행예산·매입금액과 같습니다.

입고 상세 내역 보기 · 지우기

  1. 입고 상세 내역 — 누르면 펼쳐집니다. 매입금액이 어떤 입고로 이루어졌는지 건별로 보입니다.
  2. 입고 내역 전체 삭제 — 이 버전에 불러온 입고를 모두 지웁니다.
  3. 삭제 — 잘못 들어간 입고 한 건만 뺍니다.

5단계 버전 확정

입력을 모두 저장한 뒤 버전 줄의 버전 확정을 누르고, 확인 창에서 확정을 누릅니다.

확정하면 되돌릴 수 없습니다. 실행예산·입고 내역·계약금액이 그대로 고정되고 삭제도 할 수 없습니다. 고쳐야 하면 이전 버전 복제로 새 버전을 만들어 작업하세요.

그 밖의 버전 관리

  • 이름 변경 — "2026년 3분기 기성"처럼 알아보기 쉬운 이름으로 바꿉니다. 확정된 버전도 바꿀 수 있습니다.
  • 버전 삭제 — 작성중인 버전만 지울 수 있습니다. 입력한 예산과 입고 내역도 함께 지워집니다.
  • 계약금액이 바뀌었을 때 — 프로젝트 계약금액이 이 버전과 다릅니다 안내가 뜨면, 작성중인 버전은 이 버전에 반영으로 맞춥니다.

5. 분류 · 품번 설정 관리자

집행서의 줄은 이 화면에서 정한 대분류 › 중분류 › 소분류로 만들어지고, 각 줄의 매입금액은 거기에 연결한 품번의 입고로 계산됩니다. 품번 연결이 빠지면 매입금액도 빠집니다.

  1. 설정 버전 — 분류 설정을 버전으로 보관합니다. 사용 중인 버전이 새 집행서에 쓰입니다.
  2. 대분류 ＋ — 예: 구매품비, 제작비
  3. 중분류 ＋ — 고른 대분류 아래에 추가합니다.
  4. 소분류 ＋ — 필요할 때만 추가합니다(아래 설명).
  5. 품번 연결 — 고른 중분류(또는 소분류)에 아마란스10 품번을 붙입니다.
  • 각 줄의 ▲ ▼로 순서를 바꿉니다. 이 순서가 집행서 줄 순서입니다.
  • 분류를 지우면 그 아래 분류와 품번 연결도 함께 지워집니다.
  • 설정을 고쳐도 이미 만든 집행서는 바뀌지 않습니다. 반영하려면 집행서에서 설정으로 새 버전을 만드세요.
  • 분류를 크게 바꿀 때는 현재 버전 복제로 새 설정 버전을 만들어 고친 뒤 사용 중으로 지정하면 안전합니다.

소분류와 중분류 소계

소분류는 선택 사항입니다. 중분류 안을 나눠 보고 소계가 필요할 때만 만드세요.

중분류 아래 소분류집행서에 보이는 모양
없음중분류 한 줄
1개소분류 한 줄 (소계 없음 — 같은 금액이라 생략)
2개 이상소분류마다 한 줄 + 끝에 소 계
  • 첫 소분류를 만들면 그 중분류에 붙어 있던 품번이 새 소분류로 옮겨집니다. 옮기기 전에 확인 창이 뜹니다.
  • 소분류가 있는 중분류는 소분류를 골라야 품번을 연결할 수 있고, 실행예산도 소분류마다 넣습니다.
  • 예: 구매품비 › 구입품비 아래에 구입품비, 재고사용, 설계MISS(품확), 고객요구를 만들면 네 줄 아래에 구입품비 소계가 나옵니다.

품번 검색해서 연결하기

  1. 검색어 — 품번·품명·규격의 일부만 넣어도 됩니다.
  2. 아마란스10 검색(또는 Enter)
  3. 연결 — 지금 고른 분류에 품번을 붙입니다. 해제는 아래 목록의 연결 해제.
  4. 품목 목록 새로 받기 — 방금 아마란스10에 등록한 품목이 안 보일 때 누릅니다.
  • 대소문자, 띄어쓰기, -는 구분하지 않습니다. aa00001로도 A-A00001을 찾습니다.
  • 두 단어를 띄어 쓰면 둘 다 들어간 품목만 나옵니다. 예: bush 121816
  • 한 품번은 한 설정 버전 안에서 한 곳에만 연결됩니다. 이미 연결된 품번은 ○○에 연결됨으로 표시되고 연결 버튼이 꺼집니다.

6. 관리자 기능 관리자

사용자 등록 · 관리

  1. 사용자 추가 — 로그인 ID, 이름, 권한을 넣습니다. 만들면 임시 비밀번호가 한 번만 보이니 본인에게 직접 전달하세요.
  2. 권한 — 목록에서 바로 바꿉니다. 내 권한과 마지막 관리자의 권한은 낮출 수 없습니다.
  3. 사용 중지 — 기록은 남기고 로그인만 막습니다(퇴사자 등).
  4. 비밀번호 초기화 — 새 임시 비밀번호를 만들고, 그 사용자의 로그인을 모두 해제합니다.

아마란스10 자동 로그인을 쓰면 로그인 ID를 아마란스10 사번(계정)과 똑같이 등록해야 합니다.

접속 · 보안 — 입고 조회 기간 늘리기

입고 조회 기간은 최대 366일까지입니다 오류가 나면 여기서 늘립니다.

  1. 자동 로그아웃(분) — 아무 작업이 없을 때 로그아웃되는 시간. 기본 480분.
  2. 입고 조회 최대 기간(일) — 기본 366일, 최대 1830일(약 5년)까지 늘릴 수 있습니다.
  1. 값을 바꾼 뒤 화면 아래 보안 설정 저장을 눌러야 적용됩니다.

기간 안 입고가 2,000건을 넘으면 기간을 좁히라는 오류가 납니다. 그때는 1년씩 나눠 불러오세요. 이미 불러온 입고는 중복되지 않습니다.

아마란스10 설정

더존에서 받은 연동값(API 기본 주소, 회사코드, 그룹시퀀스, callerName, accessToken, hashKey)을 넣고 연동 모드를 LIVE로 둡니다. DEMO는 시험용 가짜 데이터입니다.

  1. 값을 넣고 설정 저장을 누릅니다.
  2. 저장값으로 연결 테스트로 실제 연결을 확인합니다.

accessToken·hashKey는 암호화해 저장되며, 저장 후에는 저장됨으로만 보입니다. 바꿀 때만 새 값을 넣으세요.

활동 기록

로그인, 버전 생성·저장·확정, 입고 반영, 설정 변경, 사용자 변경, Excel 내보내기를 누가·언제 했는지 남습니다.

기록된 모든 집행서 초기화

접속 · 보안 화면 맨 아래 위험 구역에 있습니다. 시험 운영을 끝내고 실제 운영을 시작할 때만 씁니다.

  • 지워지는 것: 모든 집행서 버전(확정본 포함), 실행예산·비고, 입고 내역, 프로젝트 목록
  • 남는 것: 분류·품번 설정, 사용자 계정, 아마란스10 연동 설정, 활동 기록

확인란에 화면의 문구를 그대로 넣어야 실행되며, 되돌릴 수 없습니다.

7. 자주 묻는 질문

궁금한 질문을 누르면 답이 펼쳐집니다.

"로그인 ID 또는 비밀번호가 올바르지 않습니다"가 나와요.

아이디·비밀번호가 틀렸거나, 사용 중지된 계정입니다. 관리자에게 비밀번호 초기화를 요청하세요.

"입고 조회 기간은 최대 366일까지입니다"가 나와요.

기간을 나눠서 차례로 불러오면 됩니다(중복은 자동으로 걸러짐). 한 번에 길게 불러와야 하면 관리자가 접속 · 보안에서 최대 기간을 늘립니다.

"조회 기간의 입고 건수가 너무 많습니다"가 나와요.

기간 안 입고가 2,000건을 넘었습니다. 기간을 좁혀 여러 번 불러오세요.

매입금액이 0원이거나 예상보다 적어요.

그 줄의 연결 품번이 미설정인지, 입고 기간이 프로젝트 기간을 다 덮는지 확인하세요. 입고 상세 내역에 설정에 없는 품번 N건은 제외했습니다가 보이면, 관리자가 그 품번을 분류에 연결한 뒤 설정으로 새 버전을 만들어 다시 불러와야 합니다.

"다른 사용자가 이 버전을 먼저 저장했습니다"가 나와요.

같은 버전을 두 사람이 동시에 고쳤습니다. 화면을 새로 고쳐 최신 내용을 확인한 뒤 다시 입력하고 저장하세요.

확정한 버전을 고치고 싶어요.

확정은 되돌릴 수 없습니다. 이전 버전 복제로 새 버전을 만들어 고치세요. 예산과 비고가 그대로 복사됩니다.

분류를 고쳤는데 집행서가 그대로예요.

집행서는 만들 때의 설정을 복사해 둡니다. 설정이 사용 중인지 확인하고 설정으로 새 버전을 만드세요.

품번 검색에 품목이 안 나와요.

방금 등록한 품목이면 품목 목록 새로 받기를 누르세요. 아마란스10에서 사용하지 않음으로 된 품목은 나오지 않습니다.

"아마란스10 서버에 연결하지 못했습니다" 또는 "응답 시간이 초과되었습니다"가 나와요.

잠시 후 다시 해 보세요. 계속되면 관리자가 아마란스10 설정에서 저장값으로 연결 테스트로 확인합니다.

메뉴나 버튼이 안 보여요.

권한이 부족합니다. 관리자에게 권한 변경을 요청하세요(권한 안내).

8. 용어 풀이

계약금액
아마란스10 프로젝트의 수주금액. 버전을 만들 때의 값으로 고정됩니다.
실행예산
이 프로젝트에 쓰기로 계획한 금액. 분류별로 직접 입력합니다.
매입금액
실제로 들어온 입고의 공급가액(부가세 제외) 합계. 아마란스10에서 불러옵니다.
예산잔액
실행예산 − 매입금액. 음수면 예산을 넘긴 것입니다.
집행률
매입금액 ÷ 실행예산. 100%를 넘으면 빨간색으로 표시됩니다.
예상 이익 · 이익률
계약금액 − 매입금액, 그리고 그 금액을 계약금액으로 나눈 비율입니다.
버전
한 프로젝트의 집행서를 시점별로 남긴 것(v1, v2 …). 작성중 → 확정 순서로 진행합니다.
확정
버전을 잠그는 것. 확정 후에는 수정·삭제할 수 없습니다.
대분류 · 중분류 · 소분류
집행서 줄을 묶는 단계. 소분류는 중분류 소계가 필요할 때만 씁니다.
품번 연결
아마란스10 품번을 분류에 붙이는 것. 연결된 품번의 입고만 매입금액에 들어갑니다.
설정 버전
분류·품번 설정의 보관본. 사용 중인 설정 버전이 새 집행서에 복사됩니다.
